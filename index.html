A simple path to distribution

From release to LinuxToys in three steps.

01

Publish

Release your application through the channel that already fits your project, such as GitHub Releases.

02

Declare

Describe the package or procedure LinuxToys should use, with optional compatibility rules and hooks.

03

Reach users

LinuxToys handles the user-facing installation flow across supported distributions and tracks what was changed.
